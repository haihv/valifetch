# Versioning and stability

From 1.0.0, valifetch follows [semantic versioning](https://semver.org). The versioning and stability policy, including what counts as a breaking change, which documented defaults are covered, and how deprecations are handled, is maintained in the repository README:

- [Versioning and stability in the README](https://github.com/haihv/valifetch/blob/main/README.md#versioning--stability)

Release notes for every version are in the [changelog](https://github.com/haihv/valifetch/blob/main/CHANGELOG.md).

The deliberate API shape decisions that are locked for stability are summarised in [API design decisions](/guide/api-design-decisions).
